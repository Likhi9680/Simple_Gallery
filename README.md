# Simple_Gallery
# 🖼️ Image Gallery with Category Filters

A responsive and interactive image gallery built using **HTML**, **Tailwind CSS**, and **JavaScript**. The application allows users to browse images by category using filter buttons and view images in an enlarged lightbox.

## 📌 Features

- 🎨 Responsive gallery layout using Tailwind CSS
- 🔍 Filter images by category
- 🖼️ Lightbox for enlarged image preview
- ⚡ Dynamic rendering with JavaScript
- 📱 Mobile-friendly design
- ✨ Smooth hover animations and transitions

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (ES6)

## 📂 Categories

- 🌲 Forest
- 🐾 Animals
- 🌿 Nature
- 👥 People
- 🏞️ Country

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Image-Gallery.git
```

### 2. Navigate to the project folder

```bash
cd Image-Gallery
```

### 3. Open the project

Simply open **index.html** in your browser.

No installation or additional dependencies are required.

## 💡 How It Works

- The gallery images are stored in a JavaScript array.
- Clicking a filter button displays only images from the selected category.
- Clicking an image opens it in a fullscreen lightbox.
- The gallery updates dynamically without reloading the page.
